# For My Love

A small static website created as a personal gift for my girlfriend's 19th anniversary.

## Description

This is a simple, heartfelt static site containing a homepage and a login page with light interactivity implemented in JavaScript.

## Stack

- HTML for page structure
- CSS in `style.css` for styling
- JavaScript in `index.js` and `login.js` for client-side behavior

## Libraries

- No external libraries — built with Vanilla JavaScript and standard web technologies.

## How it was made

- Layout and visuals were created with hand-written HTML and CSS; responsive considerations were kept minimal for simplicity.
- Interactive behavior (form handling, simple animations, navigation) implemented in `index.js` and `login.js` using DOM APIs.
- Images in `assets/` and `imgs/` were optimized for web (resized and compressed) before adding to the project.
- Tested locally in browsers and verified basic functionality without a backend.
- Purpose: created as a personal, non-commercial gift for my girlfriend's 19th anniversary.

## Main files

- `index.html` — main page
- `login.html` — login page
- `index.js`, `login.js` — JavaScript logic
- `style.css` — styling
- `assets/`, `imgs/` — static assets

## How to run

Open `index.html` directly in your browser for a quick preview. For a better local testing experience, run a simple static server from the project root. Example with Python 3:

```bash
python -m http.server 8000
# Visit http://localhost:8000
```
